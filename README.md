# 林地远征 3D · 林心回响

独立的斜俯视角 3D 生存冒险网页游戏。原 2D 项目继续保留在 [last-survivo-next](https://github.com/dont-cry-522/last-survivo-next)。

[打开 3D 游戏](https://dont-cry-522.github.io/last-survivo-3d/)

## 可玩内容

- 两位骨骼动画角色：林地游侠（翻滚）、霜影（白发黑面罩、瞬移），使用 Quaternius CC0 人物、服装与动画资源，再作本项目的外观和动作适配。
- 六种武器：连发枪、霰弹枪、火法杖、手枪、穿透飞镖、暗能法器。自动索敌攻击。
- 三种环境：翡翠幽林、霜月峡谷、赤烬荒原。地形会减速，树木有实体碰撞；随机布景、不同植被与地表。
- 八种可升级能力，包含独立陨火、冰晶环、连锁落雷。经验连升会逐次提供选择。
- 五种普通敌人、怪群包围、远程落点预警、支援治疗。
- 补给和祭坛需要清理守卫，分别给予治疗/吸引经验与技能。三分钟后出现首领，冲撞、半血三重裂地及攻击后反击窗口；击败首领完成远征。
- 暂停、继续、确认结束、胜负结算、重开、声音开关、小地图与低血量提示。

## 操作

电脑 WASD / 方向键移动，Shift / 空格闪避，Esc 暂停。手机左摇杆、右闪避，横屏优先，也支持竖屏。切到其他应用自动暂停。

通过网页初次打开需联网；尚未提供完整离线缓存或安装包。3D 渲染需要支持 WebGL 的浏览器。

## 美术与声音

主角使用 Quaternius 发布的 CC0 模型、服装、发型及骨骼动作，本项目调整肤色、服装轮廓、面罩、披风、武器握持及动画混合。来源与许可见 [THIRD_PARTY_ASSETS.md](THIRD_PARTY_ASSETS.md)。场景、敌人、武器和特效仍为程序构建的简洁几何风格。人物是适用于网页游戏的风格化模型，并非商业游戏角色的高精度复刻。

音效与原创分层冒险配乐由 Web Audio 合成：每张地图有不同旋律、和声、低音与鼓组；附近怪群与首领会逐渐加强节奏。枪械爆发、火焰轰鸣、冰晶碎裂、电弧、瞬移、命中和升级使用不同的声音层。首次点击开始或开启声音后播放，可分别调节音乐/音效音量，设置在本机保存。

人物资源约 16 MB，首次进入需要下载并准备骨骼动作，界面会显示加载状态；加载失败可以重试。资源随仓库部署，不依赖运行时第三方 CDN。

## 本地开发

使用 HTTP 静态服务器运行目录，例如 `python -m http.server 8897`，然后打开 `http://localhost:8897/`。不能通过直接双击 HTML 文件加载模块。

`npm test` 执行纯规则/地图/模型检查，无需 npm install。Three.js 0.180.0 已固定在 vendor，保留其 MIT LICENSE；运行时不依赖 CDN。

## 验证与边界

7 项自动检查通过，包含 90 张地图的出生与探索点通行。浏览器测试覆盖 18 组武器/环境/视口组合，验证移动、闪避、暂停、连升选择、技能、胜利、失败与重开。连续 18 次切换后几何资源数量稳定。测试含主动触发首领和伤害的流程验证，不等同于真人通关或全面平衡测试。尚未完成安卓真机和低端 GPU 测试。

本版是可玩的 3D 首版，并未逐项搬运 2D 的 64 个技能、全部武器进阶和闯关内容。

## v2 · 声音、角色与经验反馈

- 替换两名英雄的几何体人物：男主棕色分发、绿衣、皮革护腕与护肩；女主白发、黑布面罩、白净肤色、收腰猎装、短裤、黑色过膝靴与带饰边的分叉披风。披风随行走摆动。采用骨骼站立、跑动、抬枪、施法与翻滚动作，分层混合腿部移动和上身瞄准。六种武器增加枪管、握把、金属饰件或法器核心。准备界面用更低、更近的镜头查看角色；树木和怪物仍保留首版简洁模型。
- 青色经验条加粗至电脑 12px、手机 11px，显示当前经验/所需经验与下一级；经验结晶更亮，拾取有数值反馈，升级有专属音阶。
- 新增音乐/音效独立音量和持久化静音；暂停淡出音乐，重开不会清掉音量偏好。调音量时方向键不会控制人物。
- `tests/browser-polish.cjs` 为可选 Playwright 浏览器回归（默认本地 8897）。使用已安装的 Playwright，可用 `PLAYWRIGHT_MODULE` 指定其模块位置、`BROWSER_EXECUTABLE` 指定浏览器、`TEST_URL` 指定测试地址。验证电脑及手机横竖屏经验拾取/升级、HUD 避让、音频解锁、音量键盘操作、静音跨暂停/重开/刷新保存，并离线渲染六武器、冰雷音效和各地图开头和弦检查非静音且无削波。这些信号检查不等同于真人听感评价。
- `tests/browser-heroes.cjs` 使用相同环境参数，在浏览器里加载真实角色资源，验证六武器人物、移动/站立/转向瞄准、翻滚恢复、骨骼隔离以及持续射击旋转稳定性。


## v3 · 移动和命中反馈

- 修复无目标时跑步朝向不跟随输入的问题，人物按最短方向渐进转身；射击朝向在攻击间隔内保持，避免每次发射都来回扭身。
- 按实际位移调整步频，慢走/跑步连续混合，脚步周期同步；起停有短过渡，顶住障碍物会停止迈步。增加转弯侧倾、侧向步态调整和后退步态混合；后退目前基于现有跑步动作反向播放，并非独立制作的完整后退动画。
- 无方向输入时，闪避跟随人物当前朝向。
- 普通命中改为 0.16 秒的小碎屑，取消普通击杀及火/暗普通攻击的光圈。保留范围技能和危险区域提示，伤害数值不变。
- `tests/browser-locomotion.cjs` 检查无目标朝向、反向转身、停步、碰撞停步、闪避方向，以及普通命中/击杀不再生成光圈。


## v4 · 武器路线与技能表现

- 六武器各两条互斥路线，3 / 5 / 8 级开放下一阶，选定后只推荐当前路线。升级卡显示数值、限制及取舍，准备界面显示路线名称。
- 连发枪：贯穿弹道 / 疾速机括；霰弹枪：散射风暴 / 独头重弹；火杖：余烬灼烧 / 熔核爆破；手枪：猎杀重弹 / 银鸦跳弹；飞镖：月刃齐发 / 回旋月刃；暗能：引力漩涡 / 追魂魔矢。
- 跳弹不会重复命中同一目标；回旋飞镖可在返程再次命中，能到达完整索敌距离；灼烧持续 3 秒、重复命中刷新不叠层；引力区最多 3 处，对首领牵引减弱。独立火/冰/雷法术不改变武器属性。
- 陨火下坠、柔边火焰、上升余烬；冰晶扩散与敌人霜冻提示；蓝白落雷及分叉连锁电弧；暗能收束碎片。枪弹拖迹、飞镖与元素弹体分别制作。普通攻击/击杀仍不生成光圈。
- 新特效复用几何体、材质与粒子对象，手机最多 110 个、电脑最多 190 个活动粒子；暂停冻结特效，重开清理。上限仅覆盖新技能粒子，旧场景与预警仍使用原有各自的上限。
- 11 项规则/世界检查；`tests/browser-weapons.cjs` 验证全部 12 路线的实际伤害、跳弹/回旋/灼烧/牵引/贯穿、粒子上限和清理，以及电脑和手机横竖屏路线选择。尚未做完整数值平衡评测或安卓真机性能测试。
