# 林地远征 3D · 可玩首版

独立仓库，保留已发布 2D 游戏。固定斜俯视 3D，风格化几何模型与程序骨骼动作。电脑 WASD、方向键，Shift 闪避；手机摇杆、闪避、横屏优先。全部依赖随仓库发布，不依赖第三方 CDN。

目标：一个可完成的冒险回合，角色和地图选择、六种基础武器、升级三选一、探索补给、怪群和首领、胜负结算、暂停恢复。两位角色、三种环境，独立冰火雷技能。程序模型为原创简洁风格，不声称达到商业游戏美术水平。

结构：world.js 负责地图、模型、动作；rules.js 负责数据与纯规则；main.js 负责状态、碰撞、战斗、相机及交互；style.css/index.html 负责响应布局。Three.js 0.180.0 固定版本、保留 MIT 许可。

实现顺序：规则测试 → 场景/角色 → 战斗/升级/首领 → 手机交互与可访问状态 → 浏览器实测 → GitHub Pages。验证出生通行、伤害/经验、状态清理，电脑/手机横竖屏无脚本错误；完整回合与暂停不推进时间。
