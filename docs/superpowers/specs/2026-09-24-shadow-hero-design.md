# 影裔角色设计

现有游侠与霜影保留。新增一位可选的原创角色「影裔」，让玩家在当前写实人物和低多边形怪物之间拥有一套更统一的视觉选择。

## 形象

影裔约为现有人物高度的四分之三：大兜帽、短而宽的肩、没有写实五官的深色面罩、淡紫色单条裂纹和两点眼光、碎片状短披风、较短的腿。深蓝黑是大面积色，紫灰只用于轮廓，亮色只用于眼、胸口和武器焦点。使用本项目 Three.js 程序建模与动画，不引入或复制《无畏契约》的模型、图标或音效。

## 战斗

三个可选武器为影脉法球、幽刃回旋、既有夜幕法杖。影脉法球命中同一敌人三次后产生小范围暗蚀爆发；幽刃回旋采用飞镖的穿透/回旋逻辑但使用独立的暗色外形与音效；法杖保留已有的引力或追踪路线。前两件武器各有两条三级、五级、八级递进的升级路线。

影裔的通用法术升级池用「暗幕、缚影、裂隙」替换陨火、冰环、落雷：近身暗幕减速并伤害；缚影跳向数个敌人；裂隙在敌群中短暂牵引。所有效果沿用既有粒子数量上限。闪避为一次短距影步，穿过障碍后落在安全位置，不把玩家放进树、石柱或地图外。

## 兼容与验收

主菜单可选择三位角色，影裔在电脑和手机横屏能完成选武器、攻击、升级、闪避、暂停和重开。旧两位角色的武器、升级池、动作、伤害与操作保持原样。角色模型高度明显低于原人物，在菜单和对局里与怪物使用相近的低多边形语言，并能看清移动、施法和受击姿态。自动/手动攻击模式均可玩。桌面与手机尺寸的浏览器测试，以及项目全部原有测试须通过。
