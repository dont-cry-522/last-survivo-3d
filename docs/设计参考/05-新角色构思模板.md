# 新角色构思模板

复制这份文件并改成新角色的名字，再填写空白。它是设计草稿，不会自动加入游戏。现有机制和数值请对照[资料目录](README.md)，不要把下面的建议当成已经实现的内容。

## 伙伴或召唤物

没有伙伴就写无。若有伙伴，应单独填写生命、攻击、活动范围、目标选择、受伤、倒地与复活规则。

伙伴是什么：待填写。

它自己会做什么，哪些行为由玩家控制：待填写。

主人移动、闪避、进入水域或距离过远时，它怎样行动：待填写。

它能否阻挡敌人、承担伤害或触发主人的技能：待填写。
